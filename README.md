# Traveloop 🌍 | Smart Travel Planner

**Traveloop** is a personalized travel planning application developed for the **Odoo Hackathon**. It simplifies multi-city trip planning by combining AI-driven activity recommendations with real-time budget tracking.

## 🚀 Key Features

- **Multi-City Itinerary Builder:** Add and manage different city stops (Jaipur, Lucknow, Mumbai, etc.) within a single trip.
- **AI Recommendation Engine:** Get destination-aware activity suggestions (e.g., Hawa Mahal in Jaipur, Tunday Kababi in Lucknow) and add them to your timeline with one click.
- **Dynamic Budget Tracker:** Real-time visualization of spending with a progress bar and detailed breakdown.
- **Visual Timelines:** A vertical, spine-based timeline to organize your days and activities clearly.
- **Personalized User Profile:** Dynamic user settings to manage personal data and travel preferences.
- **Public Sharing:** Generate read-only links to share your itineraries with friends.

## 💻 Tech Stack

- **Frontend:** React.js, Vite, React Router
- **Styling:** Custom CSS (Modular and Responsive)
- **Icons/Visuals:** Emoji-based icons for a lightweight, modern feel
- **Backend:** Spring Boot (connected via REST API)
- **Database:** MySQL
